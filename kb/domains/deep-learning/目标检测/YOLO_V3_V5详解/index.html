    YOLO V3/V5 详解

    本文档介绍YOLO系列早期版本V3和V5的网络结构与核心技术。

    一、YOLOv3 核心架构详解

    YOLOv3 核心参数配置

    • 边界框设置 (BBox)：采用中心点+宽高的方式（根据下采样后的特征图等分图像）。
    • 激活函数：使用 Leaky ReLU。
    • 主干网络 (Backbone)：使用 Darknet-53。

    YOLOv3 Darknet-53 网络结构

    • 计算提速：使用 3×3 卷积替代池化作下采样，使用 1×1 卷积压缩通道。
    • 残差结构：全面融入 ResNet 残差融合结构避免深层网络梯度消失。
    • 三尺度特征图：网络最后输出三个尺度的特征图进行多尺度融合，分别用于大、中、小目标的检测分支。

    YOLOv3 残差块工作机制

    • 维度瓶颈 (Bottleneck)：输入先经过 1×1 Conv降维，再经过 3×3 Conv升维。
    • 组件组合：两层卷积之间默认穿插 BN 层与 Leaky ReLU 激活层。
    • 残差相加 (Add)：最后结合输入特征通过跳跃连接直接相加。

    YOLOv3 两大核心范式创新

    • Anchor 机制：借鉴 Faster-RCNN，通过 K-means 聚类提前在一张图上设定 9 个宽高比不同的边框模版。
    • 特征金字塔 (FPN) 思想：将大特征图(52×52)用于检测小目标，小特征图(13×13)用于检测大目标。

    Leaky ReLU 激活函数的优劣势

    • 核心优点：在 x <= 0 区域给予微小斜率 (如0.01x)，解决了负输入情况下的 0 梯度弥散问题 (Dead ReLU)。
    • 核心缺点：在实践中，斜率固定带来的效果表现并不够稳定。

    YOLOv3 输出解码机制

    • 中心点解码：模型预测的是基于网格左上角的相对偏移量，通过 sigmoid 激活后加回网格坐标得到绝对中心。
    • 宽高解码：模型预测的是对数偏差，通过 exp() 指数放大后乘以预设 anchor 尺寸得到真实宽高。

    二、YOLOv5 网络架构演进

    YOLOv5 核心参数配置

    • 激活函数：隐藏层维持 Leaky ReLU 或替换为 SiLU。
    • 损失函数：定位采用 GIoU/CIoU Loss，分类采用 BCE Loss。
    • 骨干网络 (Backbone)：升级为 CSPDarknet 搭配 Focus 结构。
    • 特征颈部 (Neck)：升级为 FPN + PAN 的双向融合结构。

    YOLOv5 模型体量变体系列

    • YOLOv5n/s (微小版)：参数量极低 (1.9M/7.2M)，主打边缘端低算力实时部署。
    • YOLOv5m (中型版)：参数量适中 (21.2M)，在精度和速度间保持最佳平衡。
    • YOLOv5l/x (大型版)：参数量巨大 (46.5M/86.7M)，不顾及算力开销追求极致检测精度。

    YOLOv5 Focus 特征切片结构

    • 结构机制：将输入图片每隔一个像素取出一个值，将 1 个长宽特征折叠融合为 4 个通道并发特征，然后做卷积。
    • 效果收益：这是一种无损下采样提取策略，减少了重复卷积计算，替代了两层普通卷积带来的参数负担。

    YOLOv5 CSPLayer 结构机制

    • 结构机制：将进来的 Feature Map 沿通道一切为二，一半进入堆叠的瓶颈残差块提取，另一半直接跨阶段跃迁。
    • 效果收益：最后两者 Concat，在大幅减少参数量的前提下，增强了网络内的梯度流动速度。

    YOLOv5 FPN+PAN 双向特征融合机制

    • FPN (自顶向下)：高层具备强语义的特征经过上采样后，不断补充融合进底部的特征中。
    • PAN (自底向上)：底层具备强边缘清晰纹理的特征，经过下采样又再次补充进高层特征中，做到双向融合。

    三、数据增强与训练优化机制

    YOLOv5 Mosaic 取样数据增强策略

    • 操作机制：同时载入 4 张图片进行随机缩放与排布裁切整合。
    • 效果收益：极大丰富了图片的背景组合，变相减小了 Batch Size 要求，同时让单图内混入巨量小目标，有效增强小目标检测精度。

    YOLOv5 软性自适应优化策略

    • 自适应 Anchor 聚类：在训练第一步自动根据数据集标签的分布，用 K-means 重聚类更新出一套最优的 Anchor 长宽。
    • 自适应图像缩放：采用维持宽高比的最小 padding 灰边填充法，替代死板的强行拉伸，减少冗余计算。

    YOLOv5 与 YOLOv3 损失函数差异

    • 定位损失 (Box Loss)：V3 使用普通的 MSE（均方误差），V5 换成了收敛更快、考量更全的 GIoU/CIoU Loss。
    • 置信度预分类损失：均依然采用经典的 BCE (二分类交叉熵)。

    YOLOv5 的跨网格正样本分配机制

    • 打破中心唯一绑定：V3 时代只有中心点落进的那个网格才能生成正样本。
    • 跨网格增加正样本：V5 会判断中心点偏向该网格的哪几个象限，并强行把临近的上下左右网格也同时拉入负责该目标检测的“正样本候选群”。

    YOLOv5 核心训练控制策略 (Warmup/EMA/余弦退火)

    • Warmup (预热)：为防止刚开局发生数值爆炸，前 3 个 Epoch 会将学习率从 10% 慢慢爬坡到最高。
    • 余弦退火 (Cosine Annealing)：学习率下降不采用阶梯，而是使用平滑的余弦波函数慢慢衰减保证模型最终平稳落入局域最优点。
    • EMA (指数移动平均)：推理时不用最终那个 Epoch 导出的权重，而是采用历史上多个 Epoch 权重的平滑平均值，提升泛化度防抖。
