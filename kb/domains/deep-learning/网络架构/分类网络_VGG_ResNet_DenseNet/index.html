    分类网络：VGG、ResNet、DenseNet

    本文档深入剖析在深度学习发展史上具备里程碑意义的三大经典图像分类网络架构：VGG、ResNet 和 DenseNet。

    一、VGG 网络核心设计与参数计算

    VGG 网络小卷积核堆叠范式

    • 结构铁律：整个网络高度格式化，只使用 3×3 卷积和 2×2 Max Pooling 的交替堆叠。
    • 感受野等效：3 个 3×3 卷积层堆叠的感受野相当于 1 个 7×7 卷积层。
    • 降参增非线性：使用 3 个 3×3 的参数量只有单层 7×7 的约 55%（27C² vs 49C²），并且可以安插 3 次 ReLU，极大增强了模型非线性表达能力。

    VGG 中 1×1 卷积的战术意义

    • 增加非线性映射：在不改变特征图感受野（宽高）的前提下，实现跨通道特征层面的线性融合并紧跟 ReLU。
    • 调整通道维度：可用于灵活升高或降低数据通道（Channel）的数量，控制计算瓶颈。

    二、ResNet 残差网络突破与演进

    ResNet 网络退化难题与残差学习原理解构

    • 网络退化现象：过深的网络不光极大概率陷入梯度消失，还会出现训练误差反常升高的退化问题，这不是普通的过拟合。
    • 残差映射思想：放弃让深度神经层直接去学习原始目标函数 \(H(x)\)，而是转头去学输入与目标之间的差项（残差） \(F(x) = H(x) - x\)。
    • 优势体现：一旦网络发现“继续加深反而有害”，它就可以轻易把这几层残差层权重归零，实现 \(H(x) \approx x\) 的恒等保底直通，保证至少不会比浅层差。

    ResNet Basic与Bottleneck两种残差模块差异

    • Basic Block (浅层专用)：用于 ResNet-18/34。直接由两个 3×3 的卷积连读再加上原本输入连接组成。
    • Bottleneck Block (深层省流版)：用于 ResNet-50/101/152。由于通道数极高，采用 1×1 (降维) → 3×3 (特征提取) → 1×1 (升维还原) 的沙漏状组合，巨幅锐减运算量。

    三、DenseNet 稠密连接优势与特征重用

    DenseNet 密集传递与特征重用机制

    • 拓扑结构改变：相比ResNet 只是和上一层的出口产生 Add 映射，DenseNet 则是每一层都会接受其前面所有层特征张量的 Concatenate。
    • 最大化信息流动：这让梯度的穿透路径直通浅层到深层，不仅有效实现了隐式深度监督，极大加速收敛，还利用低维特征不断拼贴直接提升了精度上限。

    DenseNet Growth Rate 与 Transition 结构

    • 增长率 (Growth Rate / K)：为了避免层层堆叠导致通道大崩盘，DenseNet 设定每一层自己本身只单独产生极少量（如 k=32）的新特征图并轨。
    • Transition Layer：部署在两个大 Dense Block 之间，强制进行一次跨模块的 1×1 卷积压缩和 2×2 平均池化，进一步镇压暴涨的张量通道数。

    四、技术横向评测与选型

    VGG / ResNet / DenseNet 架构级横评对比

    • VGG 特征：无跳接无旁支，纯直筒结构，证明了“层深就是王道”。但因无残差致使深层直接梯度消失，模型极度臃肿。
    • ResNet 特征：采用 Add 对向相加进行特征融合；间接复用。在性能与泛用度之间达成黄金平衡。
    • DenseNet 特征：采用 Concat 将通道直接缝合；直接复用。由于不需要再算那么多新权值，因此在相同的精度点下能做到参数量最省。

    经典图像分类网络实战选型指南

    • 中庸全能 (工业界黄金万金油)：首选 ResNet-50；基本通吃一切特征提取需求（如YOLO特征骨干）。
    • 极尽榨取参数或精度极限：选择 DenseNet，适合小样本下的极高精度要求。
    • 极致资源受限或移动端轻量：可向后退化使用 ResNet-18 / ResNet-34。
