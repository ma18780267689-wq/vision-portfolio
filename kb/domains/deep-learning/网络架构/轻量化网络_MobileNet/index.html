    轻量化网络：MobileNet 系列

    本文档介绍专为移动端计算瓶颈和边缘 IoT 设备部署而设计的终极轻量化网络架构——MobileNet系列。

    一、MobileNet V1：深度可分离卷积的开创

    MobileNet V1 深度可分离卷积原理解析

    • 深度卷积 (Depthwise)：先利用 \(C_{in}\) 个独立的单层卷积层（如 3×3×1）分别仅对输入的单一通道负责平面特征提取。彻底切断通道间的信息交换。
    • 逐点卷积 (Pointwise)：随后立刻补上 \(C_{out}\) 个 1×1 的卷积接力，这层卷积横向打通所有通道，将刚刚抽取的孤立通道特征进行加权组合映射。
    • 效能暴涨：相较于传统的 \(3 \times 3\) 全尺寸标准卷积，这套将空间与通道物理剥离的组合拳，直接将计算量和参数量双双砍去了接近 8 到 9 倍（约为原先的 \(1/9\)）。

    MobileNet V1 超参瘦身乘数设计

    • 宽度乘数 (α, Width Multiplier)：取值范围通常在 (0, 1] 之间。在构建网络时，所有卷积核的基准通道数都会硬性乘上这个比例，以牺牲厚度换取极致轻薄。
    • 分辨率乘数 (ρ, Resolution Multiplier)：控制输入图片的初始长宽。两者同时作用时，总体计算量（FLOPs）会按照 \(\alpha^2 \rho^2\) 的几何倍数极速缩水。

    二、MobileNet V2：倒残差结构与线性瓶颈

    MobileNet V2 倒残差架构核心设计

    • 传统残差 (ResNet)：先用 1×1 降通道“挤牙膏”，再用 3×3 提特征，最后 1×1 升维。这叫“宽-窄-宽”。
    • 倒置残差 (Inverted Residual)：由于轻量化网络本身通道少的可怜，如果再强行“挤牙膏”会摧毁张量。所以 V2 决定先用 1×1 扩充倍率（通常乘6倍）强行“撑宽”特征空间，在宽敞高维里用 3×3 DW 卷积提炼边缘，最后再用 1×1 压缩回收。即“窄-宽-窄”。

    MobileNet V2 线性激活瓶颈保护论

    • ReLU塌缩灾难：研究发现，ReLU 虽然能剔除无用负值，但一旦将特征空间先做降维压实后，此时的高密度残余特征碰到 ReLU 就会发生不可逆的致命塌缩断点。
    • 线性瓶颈解法：V2 大胆砍掉了最后一个 1×1 恢复尺寸卷积后面的 ReLU6 激活，让其维持纯粹的 Linear 线性映射输出（也叫 Linear Bottleneck），完美保全了信息纯度。

    三、MobileNet V3：NAS搜索与机制拼接

    MobileNet V3 NAS 神经搜索架构与 h-swish

    • NAS + NetAdapt 搜索：主体大框架及每一个模块具体的扩充比例、通道数，全交由强化学习硬件感知算法进行暴力的 AutoML 机读搜算。
    • h-swish 伪函数替换：原本被证明效能拔群的 Swish 函数由于含有 Sigmoid 计算过于昂贵耗时。被 V3 主创替换成了一个名为 \(x \cdot \frac{ReLU6(x+3)}{6}\) 的山寨近视版 h-swish，几乎在零延时的代价下保住了原版的高精度曲线。

    MobileNet V3 植入 SE 通道注意力机制

    • 全局视野微缩：对宽维度的空间特征先用全局平均池化压缩成单点，接着通过两层全连接获取了纵横向的上帝视角通道依赖。
    • 注意力叠加倍乘：基于获得的 [0, 1] 权值组，反过来给特征图中那些具备价值的通道（如有眼、有嘴的通道）叠加大数值，对无用杂讯通道（如单纯的背景）乘以近 0 极小值抹除干扰。

    四、轻量化技术总结与实战部署指南

    业界常见前沿模型压缩优化策略盘点

    • 低精度量化 (Quantization)：把庞大的 FP32 浮点数粗暴修剪压缩成极其便宜的 INT8 整数块。
    • 枝叉修剪 (Pruning)：在训练收敛后，直接定点摘除网络中权重绝对值极小且不怎么受刺激的死神经元与僵尸通道。
    • 知识蒸馏 (Knowledge Distillation)：让一个计算缓慢的庞大“老师”模型先练熟，然后引导一串毫无负担的“学生”轻量模型模仿老师的软反馈结题思路。

    MobileNet 系列模型实战选型与训练建议

    • 极限精度上限：无脑选择 MobileNetV3-Large 版。
    • 极度严苛的穿戴或嵌入式设备：建议使用最初版的 MobileNetV1 或 V2 配合极小的 Width Multiplier。因为早些年的廉价 NPU/TPU 仅仅对基本的纯 3×3 或纯 1×1 加速极佳，对过于花哨的 SE 结构很可能会遇到编译器兼容甚至严重掉速灾难。
    • 训练强化建议：因为轻型网络很容易受限于自身参量出现拟合疲软现象，故强烈建议堆满一切数据增强（如 Mixup、CutMix），并适当放宽正则（不宜过强的 Weight Decay）。
