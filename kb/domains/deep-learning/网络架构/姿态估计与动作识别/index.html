    姿态估计与动作识别

    本文档基于原始积累脉络，详细梳理人体人体姿态估计领域的核心网络 AlphaPose，以及图卷积动作识别网络 ST-GCN 的核心架构与运作机制。

    一、AlphaPose 姿态估计算法架构

    AlphaPose 自顶向下的模型检测管线

    • 自顶向下思想：网络结构秉持“先宏观再微观”的流程，第一步优先检测并全图框选出所有的独立人体单元。
    • 降维检测：将复杂的全图多人动作交缠问题，降维转换成基于单个人体裁切框内去检测具体的单人肢体节点分布，精度极高。

    AlphaPose 并行 SPPE 沙漏模型特征提取器

    • 主要识别网络：采用 SPPE (堆叠沙漏模型, Stacked Hourglass) 充任主要的肢体姿态骨干识别提取网。
    • 并行正则化分支：为了优化并且让这套非常深的沙漏网络免于陷入局部最优的情况，AlphaPose 在训练阶段创新引入了一条新的 并行 SPPE 分支，专职充当辅助正则化器的功效，最终收敛能力被大幅拔高。

    AlphaPose 参数化感知姿态 NMS 去重

    • 传统局限：普通的图像 NMS (非极大值抑制) 只考核两个人体大检测框的 IoU 面积碰撞比，由于运动者常常互相遮挡重叠极多，非常容易引发误删、漏删。
    • 参数化机制重构：专门提出了一种适配关节点的参数化的 NMS，该算法细致入微地直接根据骨架节点的个位置信度预测与绝对向量距离开销来进行去盲清重，完美区分拥抱中两个独立的人体。

    二、时空图卷积网络 (ST-GCN) 基础理论

    欧几里得与非欧几里得的数据卷叠差异论

    • 欧几里得结构数据：泛指诸如正常图像这样排列死板整齐的数据拓扑，在这个网格里非常容易找到任意像素的“上下左右邻居结点”。
    • 非欧几里得结构数据：也就是随意排布的网状互联事物。对于数据中的某一个孤点，极难去定义邻居边界，或者不同节点的单边邻居数量都不一样。人体动作骨架就是天生的非欧图纸。
    • 图卷积本质：普通的图像卷积是聚集小方块相邻点。图卷积做的事情同样是“聚合邻域信息”，唯独不同的是面对非欧形式，它的核心执行实质是做矩阵乘法。

    ST-GCN 基本时空模块堆叠范式

    • 单层切割组成：ST-GCN 对极为复杂的骨架运动切分了感知系。它的一层模块 = 一个空间图卷积(核心) + 一个时间卷积。
    • 时空堆叠前向：经过开局处理后，直接串联数十个这样的基础组件模块直通全网，输出前经过全局平均池化（Global Avg Pool）接入全连接并归总动作分类词条。

    三、ST-GCN 核心执行机制与特征推演

    ST-GCN 五维时空输入张量构型 (N,C,T,V,M)

    对于传入的所有视频源，送入第一层前会经历严谨的规范化，打成标志性的 (N, C, T, V, M) 维张量： - N (视频数量)：每一次批读取喂给网络的 Batch Size，也是动作短片数量。 - C (关节特征)：对于每一个单独关节点拥有的数据维度，通常等于 3 个特征（x位置坐标、y位置坐标以及 acc关节感知置信度）。 - T (关键帧数量)：短视频在时间轴上的抽样厚度，一般设定一个截断视频拥有 150 段长时帧。 - V (单一人员关节数)：单人打点数，由于是通用建模常常遵循一般标注规则打出 18 个主干关节。 - M (捕获人员总数)：通常代表这一帧画面提取的人员数，这里一般选择置信度平均最高的 2 个人参与对决。

    ST-GCN 基于重心的向心图拓扑分类法则

    • Label 0 (基准根节点)：也就是以某一个节点自己本身到整个人体画面重心的距离尺度化为基准比较底盘。
    • Label 1 (向心节点)：在它的所有的邻接串联关节当中，但凡距人体物理重心的远近长度小于 0 号基准值的，全部划拨为向心聚拢类点集。
    • Label 2 (离心节点)：在所有邻接点中距离重大于基准发散至末端的则被视为离心发散点集。

    ST-GCN 骨架信息聚合特征演算三步曲

    • 步骤 1：全网拓扑重加权：先引入一个全向可学习的权值矩阵（Learnable edge importance weight），它长得和邻接矩阵一般大然后做按位相乘。用来赋予动作核心发力关节极大的权重系数并彻底抑制死寂节点。
    • 步骤 2：空间领域残差融合 (GCN)：将此加权矩阵送进 GCN。此阶段引入了极像 ResNet 做法的附加残差结构 (单独并行一个CNN+BN) 计算获得 Res补偿，强行与 GCN 结果按位相加聚合为最终的空间维度形体反馈。
    • 步骤 3：时间纵向串透 (TCN)：最后收尾阶段完全交由 TCN 时间卷积池处理。由于空间已经搞定，这里本质是普通的一维 CNN 探针（确保时间轴向里的 Kernel Size 必须大于1），无缝汇集多帧间动作走势完成时间信息收缩。
