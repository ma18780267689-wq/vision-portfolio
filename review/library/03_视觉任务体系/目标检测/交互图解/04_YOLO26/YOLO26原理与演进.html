YOLO26 · 原理与演进

让早期训练获得丰富监督，
让后期优化更贴近推理。

双分支检测器通过一对多补充监督，通过一对一学习无需非极大值抑制（NMS）的输出。两条分支的职责不同，在训练各阶段的作用也不同。YOLO26 的渐进损失据此调整分支权重，使优化重点从早期的丰富监督，逐渐转向端到端推理使用的一对一分支。

本页详述渐进损失、小目标感知标签分配（STAL）与混合优化器 MuSGD，说明它们如何衔接双分支训练。交互计算分支权重、示例加权损失与空间候选资格，不运行神经网络训练。查看 MuSGD 怎样更新参数 →

00 / 先确定改动的位置

结构以 YOLO11 为基础，
端到端训练衔接 YOLOv10 的思路。

YOLO26 是 Ultralytics 的实时视觉模型系列。论文以 YOLO11 为结构基础，同时采用与 YOLOv10 相关的双分支、一致标签分配思路，支持非极大值抑制（NMS）之外的端到端输出路径。结构来源与监督设计的联系需要分别判断。

图中展示的是论文的端到端路径。在当前官方文档中，常规预测与验证默认走一对多加 NMS；要比较端到端延迟，应明确选择一对一，并核对导出后端。查看官方部署口径 · 与 YOLO11 比较时怎样选。

其目标是兼顾检测能力、推理效率与部署简洁性。主要改动分布在框的输出表示、分支损失组合、候选筛选和参数更新四个环节。

01 / 丰富监督与端到端输出，仍有阶段性差异

两个分支都参与训练，
为何不始终采用相同权重？

一对多分配允许多个候选预测学习同一真实目标，因此提供较丰富的正监督。一对一分支使用更严格的对应关系，学习用于免 NMS 推理的输出。双分支设计兼顾了这两种需求，但尚需确定：不同训练阶段，各分支的损失应在总目标中占多大权重。

训练初期：先建立检测能力

特征表达与候选预测尚不充分。一对多提供较丰富的正监督，有利于建立共享特征与基本检测能力。

训练后期：更重视部署分支

端到端部署最终使用一对一分支。随着训练推进，需要充分优化这条输出路径，使训练重点更贴近实际推理需求。

作者认为，始终采用固定且相同的分支权重，没有充分利用这种优化上的不对称性，可能使推理分支优化不足。因此，YOLO26 采用渐进损失（Progressive Loss），逐步降低一对多权重、提高一对一权重。

渐进损失的核心作用，是根据训练阶段调整双分支的优化重点。两条分支持续接受监督，变化的是它们的损失如何参与总目标。

问题背景与方案依据：论文 §3.3.2。双重分配的基础见 YOLOv10 双分支职责；分配怎样构造监督目标，见 样本分配与损失。

02 / 保留各自监督，调整组合权重

从早期的一对多为重，
逐渐转向一对一为重。

两条分支分别完成样本分配、目标构造与损失计算，得到一对多损失和一对一损失。渐进损失在组合两者时，使用随训练进度变化的权重：

L总 = w一对多(t) L一对多+ w一对一(t) L一对一t 表示当前训练轮次；两个 w 分别是分支损失的加权系数，且两者之和为 1。L一对多、L一对一 是各分支按自身检测损失规则计算后的结果。分支权重与匹配度量中的分类、定位指数是不同参数。

论文默认从 一对多 0.8、一对一 0.2，线性调整到 一对多 0.1、一对一 0.9，按训练轮次更新。两条分支从开始就参与训练，一对多分支在后期也没有被完全关闭。

3.200 + 0.400 = 3.600

实际损失贡献取决于“系数 × 分支损失”，不能只看系数。总值随拖动变化，不表示模型学得更好、损失已经收敛或检测精度提高。

w一对多(t) = max(1 − t / max(E − 1, 1), 0) × (0.8 − 0.1) + 0.1

03 / 将权重放回一次训练迭代

分配决定监督责任，
渐进损失决定分支权重。

  1. 前向计算产生两组预测。

    主干特征提取网络与特征融合网络提供多尺度特征，两套检测头分别产生一对多与一对一预测。

  2. 分别建立预测与真实标注的对应。

    两条分支按各自分配设置构造监督。损失系数提高，不会自动增加被选为正样本的预测数量。

  3. 计算两份分支损失。

    框与类别等单项监督先按各分支的损失规则组织，得到 L一对多 和 L一对一。它们并不是正样本数的简单求和。

  4. 使用当前轮次的系数组合。

    总目标为 w一对多L一对多 + w一对一L一对一。同一轮次内的训练批次沿用相应调度系数。

  5. 反向传播，再由优化器更新参数。

    系数缩放对应可求导路径上的梯度；哪些参数能收到该分支的梯度，还由计算图及停止梯度操作决定。

分配如何落到掩码、框与类别目标：样本分配与监督机制。YOLO26 的具体分配设置需要结合自身实现，不能把 YOLOv10 的全部参数原样套用。

权重增大，并不改变梯度能否通过的路径

当前核对的官方普通检测实现中，一对一头读取 xi.detach() 形成的特征。它的损失仍可训练一对一检测头自身参数，但不直接回传到共享的主干与特征融合网络。

一对多分支

  • 读取可回传梯度的共享特征。
  • 损失影响一对多头与共享网络。
  • 该路径的梯度受一对多损失系数缩放。

L一对多 → 一对多头 → 共享网络

一对一分支

  • 读取经过停止梯度处理的共享特征。
  • 损失更新一对一头自身参数。
  • 提高权重不会解除停止梯度。

L一对一 → 一对一头；到共享网络的梯度被阻断

对所列双分支普通检测路径而言，可以进一步写成：

∇θ共享L总 = w一对多 ∇θ共享L一对多∇θ一对一头L总 = w一对一 ∇θ一对一头L一对一θ 表示相应部分的参数，∇ 表示损失对参数的梯度。这里仅展示分支损失在所述计算图中的路径，不包含优化器的动量、权重衰减等更新细节。

一对一权重为 0.9，不表示它更新 90% 的参数，也不保证实际梯度贡献为 90%。它表示该分支损失乘以 0.9；梯度大小还取决于分支损失本身、参数与计算图。

依据：Detect.forward 中的一对一输入与 detach；E2ELoss 的损失加权。以上限定为所列实现，不推定所有端到端检测器均有同样梯度路径。

04 / 先有有效候选，才能比较匹配质量

目标太小，可能连参与匹配的
预测位置都没有。

任务对齐样本分配（TAL）先检查预测位置的参考点是否位于真实标注框（GT）内部，再根据分类与定位质量选择正样本。参考点由特征网格和步长确定，不等于网络回归出的预测框中心。

参考点是离散排列的。一个很小的 GT 可能落在相邻参考点之间，导致框内没有有效位置。此时，即使设置了 Top-10，数量规则也不能凭空创造合格候选。这是 STAL 首先要修正的问题。

保持 GT 不变，单独调整用于筛选的区域

STAL 以 GT 中心为中心，按宽、高分别判断是否需要补足候选范围。临时候选窗口只决定哪些参考点能够参与匹配；匹配评分、最终监督目标和框回归仍使用原始 GT。它不根据当前预测框是否很小来触发。

候选资格：参考点是否位于临时候选窗口内定位监督：预测框仍然拟合原始 GT取得候选资格，不等于自动成为正样本，也不等于获得更高损失权重。后续仍需经过 TAL 评分、数量筛选与冲突处理。

论文与当前代码的尺寸规则有什么差别？（核对日期：2026-11-03）

论文 §3.3.3 的公式：某条 GT 边长小于最小预测步长时，将候选窗口的对应边长设为参考尺寸。步长为 8、16、32 时，即 d < 8 → 16；宽和高独立处理。因此 4×5 对应 16×16，4×30 对应 16×30，而 12×12 保持不变。

当前官方 main 的普通水平框实现：某条边长小于第二级步长时，将其补足到该步长。默认表现为 d < 16 → 16；因此 12×12 也会得到 16×16 的候选窗口。两者保持 GT 中心和回归目标不变，但触发范围不同。本页明确区分两种口径，不将它们写成完全一致。

有了候选资格，后面仍然怎样选择？

STAL 补充的是 TAL 的空间筛选规则。进入候选集合后，仍按分类分数与定位质量的组合排序，再根据分支设置选择。一对多提供丰富监督，一对一服务于免 NMS 输出；它们不是先选定小、中、大中的某一个尺度，再只训练这个尺度。

05 / 损失产生梯度，优化器决定怎样更新参数

保留动量 SGD 的更新，
再引入矩阵结构上的调整。

梯度下降根据损失对参数的梯度更新权重。带动量的 SGD 将当前与历史梯度累积起来，形成近期梯度趋势。对于一个权重矩阵，这些趋势仍按对应权重的位置排列，并非把历次梯度逐行存入矩阵。

已有更新还存在什么问题？

动量解决了怎样利用历史梯度的问题，但不专门均衡同一矩阵中不同奇异模式的强度。当更新主要集中在少数模式上时，其他模式的相对更新可能很小。Muon 据此对动量形成的待更新矩阵进行近似正交化，重新调整各模式的相对尺度。

这里的“模式”是整个矩阵的一种数值变化模式；强弱由对应的奇异值大小描述，不代表某个目标类别、某个权重的重要性，也不保证弱模式一定包含有用信息。这是方法动机，不是所有检测任务都存在同样问题的结论。

YOLO26 怎样使用 Muon？

MuSGD 将 Muon 与动量 SGD 组合起来。当前核对的官方实现让二维线性权重、四维卷积核接收两种更新，一维偏置与归一化缩放等参数使用 SGD。卷积核先展平成矩阵计算 Muon 更新，再还原到原来的形状；不会给推理网络增加新层。

STAL / TAL → 分配监督对象渐进损失 → 组合分支损失 → 反向传播得到梯度MuSGD → 利用梯度与优化器状态更新参数样本分配、损失组合和参数更新处于不同环节。Muon 也不改变一对一头已有的停止梯度路径。

这组结果说明，作者所测的 MuSGD 配置在更少轮数下取得更高精度。它没有单独证明收益全部来自正交化，也不能把轮数减少直接当作实际训练时间减少：还需比较每步耗时、达到同等精度的成本，以及重复实验的波动。

Muon 是优化器中的矩阵更新方法；MuSGD 是 YOLO26 使用的混合方案。它们不同于渐进损失的双分支权重，不能把两套系数混为一谈。实际 Newton–Schulz 迭代是近似计算，也不等于把所有奇异值精确变为 1。

机制：Muon 原作者说明；训练方案与结果：YOLO26 §3.3.1、§4.3.2、表 4；实现：MuSGD、参数分组与构造。main 核对日期：2026-11-03，复现时需固定版本。
